giong 1.0
1.5newest1.41.31.21.11.0

This is the documentation of giong 1.0 (v1.0.1). The newest release is 1.5: read this page for 1.5.

Runtime

giongExecutor, io_uring, epoll and kqueue drivers and IOCP; TCP, UDP, Unix sockets, files, timers, DNS, channels.

Protocols

giong-tlsTLS 1.2 and 1.3 for servers and clients on rustls. No OpenSSL.giong-httpA strict HTTP/1.1 and HTTP/2 server, HTTPS behind a feature, and a pooled client.giong-compatTokio's and futures-io's I/O traits for giong's streams, for h2, tokio-rustls and the like.

Clients

giong-postgresPostgreSQL client and pool; statements of every task pipeline together.giong-mysqlMySQL and MariaDB client and pool, built the same way as giong-postgres.giong-redisRedis client on RESP3: pipelining across tasks, Pub/Sub, a pool.

Framework

giong-webRouter, middleware and JSON on giong-http; errors as coded problem+json.

Tooling

giong-mcpA read-only MCP server: an agent sees what each worker, task and pool is doing.

Operate

Deploymentio_uring in Docker, Docker Compose and Kubernetes, the locked-memory limit, kernel quirks, restarting on the same port.StabilityWhat the 1.x promise covers: the API and its documented behaviour, error codes, environment variables, the minimum Rust version and the kernels.Error codesEvery GIONG-E code: what went wrong and how to fix it.
