# GIONG-E5018: the service did not start listening

> giong 1.5.0 · https://giong.run/docs/errors/E5018/ · source: https://github.com/giong-run/Giong/blob/v1.5.0/docs/errors/E5018.md

Raised by the `giong` command (giong-cli): `giong dev`. In JSON output: `"code": "GIONG-E5018"`.

## What happened

The new build of the service did not accept connections within the time `giong dev` waits for it (30 seconds by default). The previous build keeps serving.

## How to fix it

- Check what the service does before it binds its listeners: a database it cannot reach, a migration that waits on a lock.
- If it legitimately needs longer, raise the wait: `giong dev --ready-timeout 120`.
