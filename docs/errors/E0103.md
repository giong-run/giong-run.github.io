# GIONG-E0103: no address to use

> giong 1.4.2 · https://giong.run/docs/errors/E0103/ · source: https://github.com/giong-run/Giong/blob/v1.4.2/docs/errors/E0103.md

Raised by `giong::net` connect and bind. In code: `giong::error::Code::NoAddresses`.

## What happened

A connect or bind was given an empty list of addresses, so there was nothing to try.

## How to fix it

- Pass at least one address. To connect, a host name that resolves to one also works; `bind` takes IP addresses only ([GIONG-E0100](https://giong.run/docs/errors/E0100.md)).
