Error codes

Every GIONG-E code: what went wrong and how to fix it.

giong 1.5
1.5newest1.41.31.21.11.0
.md

Every error giong raises itself starts with a code and ends with a link to its page here:

GIONG-E0102: no address found for db.internal. Fix: check the spelling of the name,
/etc/hosts, and the DNS servers in /etc/resolv.conf (in a container, the network it is
attached to). See https://github.com/giong-run/Giong/blob/main/docs/errors/E0102.md

Errors giong only passes on, such as "connection refused" from the kernel, have no code. Functions still return std::io::Error; match on the code, not on the message:

use giong::error::{self, Code};

fn on_error(err: &std::io::Error) {
    if error::code(err) == Some(Code::HostNotFound) {
        // ...
    }
}

giong-http, giong-web, giong-tls, giong-postgres, giong-mysql, giong-redis, giong-mcp and giong-compat use the same codes. A code is never reused or renumbered, and its page stays when it is no longer raised.
