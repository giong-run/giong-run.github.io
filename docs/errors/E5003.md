# GIONG-E5003: the Rust compiler is too old

> giong 1.5.0 · https://giong.run/docs/errors/E5003/ · source: https://github.com/giong-run/Giong/blob/v1.5.0/docs/errors/E5003.md

Raised by the `giong` command (giong-cli): `giong doctor`. In JSON output: `"code": "GIONG-E5003"`.

## What happened

The Rust compiler on the `PATH` is older than the minimum the giong crates need (Rust 1.80; giong-quic and HTTP/3 need 1.85).

## How to fix it

- `rustup update stable`, then check with `rustc --version`.
- If the project pins an older toolchain in `rust-toolchain.toml`, raise it.
